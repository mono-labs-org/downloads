# Monolythium Downloads

Public release artifacts for the Monolythium ecosystem. Signed binaries for all platforms.

## Apps

### Monolythium Desktop Wallet

Cross-platform desktop wallet for Monolythium. Staking, multi-network, Ledger support.

| Platform | Format |
|----------|--------|
| Windows | `.exe`, `.msi` (code-signed) |
| macOS (Apple Silicon) | `.dmg` |
| macOS (Intel) | `.dmg` |
| Linux | `.AppImage`, `.deb` |

[**Download latest**](https://github.com/mono-labs-org/downloads/releases?q=desktop-wallet)

---

### MonoLands

Open-world voxel survival game built with Rust and the Bevy engine. 48 procedurally generated planets.

| Platform | Format |
|----------|--------|
| Windows | `.zip` (code-signed) |
| macOS (Apple Silicon) | `.tar.gz` |
| Linux | `.tar.gz` |
| Browser (WASM) | `.zip` |

[**Download latest**](https://github.com/mono-labs-org/downloads/releases?q=monolands)

---

### Wallet Gen

Offline mass wallet generator. Generates thousands of wallets with bech32 and 0x addresses.

| Platform | Format |
|----------|--------|
| Windows | `.zip` (code-signed) |
| macOS (Apple Silicon) | `.tar.gz` |
| macOS (Intel) | `.tar.gz` |
| Linux | `.tar.gz` |

[**Download latest**](https://github.com/mono-labs-org/downloads/releases?q=wallet-gen)

## Release Tags

Tags follow the convention `{app}-v{version}`:

- `desktop-wallet-v0.1.0`
- `monolands-v2.4.0`
- `wallet-gen-v0.1.4`

## Verification

All Windows binaries are code-signed via [SignPath](https://signpath.io). macOS binaries are signed with Apple Developer certificates where available.
